## 错误 1：CS1061 —— `is not T x` 会拆箱

`_engine?.Current` 的类型是 `TrackRef?`（`PlayerEngine.Current` 声明为 `TrackRef?`）。
但模式 `is not TrackRef cur` **已经把 `TrackRef?` 拆箱成 `TrackRef`**，
所以 `cur` 是 `TrackRef` 而非 `TrackRef?`，再写 `.Value` 就多了一层。

**修法**：5 处 `cur.Value.GameId` → `cur.GameId`、`cur.Value.TrackNo` → `cur.TrackNo`、
`PlayTrack(cur.Value)` → `PlayTrack(cur)`。

**反证**：`NextRef()` / `PrevRef()` / `RandomRef()` 里同样写 `cur.Value` 却没报错——
那里的 `cur` 确实是 `TrackRef?`。编译器没报就是类型判断的最好证据。

> 教训：nullable 值类型 + `is not T x` 模式匹配，变量会被拆箱，不要再 `.Value`。
> 判断依据就是看编译器报不报 CS1061。

## 错误 2：WasapiOut 过时（警告，非错误）

NAudio 3.x 主推 `WasapiPlayer`，`WasapiOut` 标了 `[Obsolete]`。
查 NAudio 官方文档与 GitHub issue #613（markheath 本人回复）确认新 API 用法：

```csharp
using var player = new WasapiPlayerBuilder()
    .WithSharedMode()
    .WithEventSync()
    .WithLatency(100)
    .Build();
player.Init(waveProvider);     // 只收 IWaveProvider，和 WasapiOut 一样
player.Play();
```

**原来是**：`new WasapiOut(AudioClientShareMode.Shared, true, LatencyMs)`
（第二参 `true` = useEventSync，第三参 latency ms）

**改成**：`new WasapiPlayerBuilder().WithSharedMode().WithEventSync().WithLatency(LatencyMs).Build()`

成员映射全部对得上（已核对 XML 文档）：

| WasapiOut | WasapiPlayer |
|---|---|
| `Init(IWaveProvider)` | `Init(IWaveProvider)` ✓ |
| `Play()` / `Stop()` / `Pause()` | 同名 ✓ |
| `PlaybackState`（`NAudio.Wave.PlaybackState`） | 同名 ✓ |
| `Dispose()` | `Dispose()` ✓ 阻塞式停止并释放 |

顺带删掉了不再需要的 `using NAudio.CoreAudioApi;`。
