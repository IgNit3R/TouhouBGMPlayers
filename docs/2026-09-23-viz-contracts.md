## 一、播放语义

- **暂停 = 慢慢衰减到 0（~1 秒）；停止/切曲/播完 = 立刻清零** —— 差别是「**速度**」不是「终点」。
  ⚠️ 方案 §二 的「停在 15%」**已作废**（用户 2026-09-21 拍板；方案已追加 §十二 修订）。
- 绘制跟 vsync、分析限 60Hz；**取样点 = 音量后**（`PlayerEngine.cs:86`）。

## 二、分析器与渲染器的接口纪律

- **`Revision`（真重算 +1）与 `ResetRevision`（归零 +1）是两个契约**，别合并；
  **换源必须 `Rebind`**（new 分析器会让归零信号悄悄丢）。
- ⚠️ **渲染器不许读 `f.Active` 覆盖「分析器已算好的显示量」**（暂停时已乘好衰减）——
  唯一例外是 D 的余辉（它读「推不推新一层」）。踩过：B 把波形拍平 → 「衰减没多久往小跳」。
- **`VizTap` 三纪律**：零分配 / 无锁 / **返回值原样透传**（返回 0 会让 `WasapiPlayer` 判定流结束）。
  `IsPlaying` = 「音频线程最近 250ms 有没有拉数据」（**没有第二个真相源**）。

## 三、窗口与布局

- ⚠️ **贴附/内嵌是「状态」**：必须写成**收敛的同步**，不能写成「建对象时读一次」——否则运行中改设置
  只走 `RefreshPlacement()`（没有宿主时是空操作）→ 宿主永不被建，现象是「设置不起作用」。
- ⚠️ **几何所有权**：贴附时几何是**宿主算的**，`Closing` 不能回写；运行期用户拖宽要**立刻写设置**。
- ⚠️ **共用 XAML 资源必须放应用级主题**（放窗口 `Resources` 里 → UserControl 够不着 → `XamlParseException`）。

## 四、性能

- **唯一旋钮 = D 的余辉层数**（`VizSettings.TrailLayers`，默认 10）。
  **`帧距 ≈ 5.1 + 1.05 × 层数`（ms）**；抽稀折线**无效**（成本是墨量 = 层数 × 路径长度 × 线宽）。
- 🔑 **量「录绘制指令」≠ 量「把它画出来」→ 要量帧距**。诊断叠层：可视化窗口 **F12 / R**。

## 五、封面（M7，已实现并实机验证）

- **每作一张、固化进程序集**。素材归一化后放 `assets/cover/embed/<id>.jpg`
  （**长边 512 JPEG**，2.64MB；原图 38.9MB 留在 `assets/cover/` 不引用），csproj 用**通配**
  `<Resource Include="..\assets\cover\embed\*.jpg">` ⇒ 加图不用改工程。
  读 `pack://application:,,,/Resources/cover/<id>.jpg`（见 `VizCover`）。
- ⚠️ **副版 `<id>_alt.jpg` 存在才用、否则回退主版** —— th13「不跟霊界版走」就是这么实现的，**零特例代码**。
- ⚠️ **封面跟「播放」不跟光标**（与底部两行文字刻意不同）；新建宿主时靠 `_currentCover` **补课**。
- ⚠️ 改 id 清单要同步 `VizSelfTest` 里那条封面检查（它正向扫 29 个 id + **反向枚举程序集里的素材**）。
