用户验证 build 31：闪退修复 ✓、预读 ✓、图标 ✓；发现两个新问题。
仓库已被用户提交到 1.0b（含 build 31 修复，另加 GPL v3 license 提交）；
本轮修复定版 **1.0c**。

## 修复 1：点「应用」输出设备不生效（只有「确定」生效）

根因：设备切换等副作用都在 `OpenSettings` 里 `ShowDialog()` **返回后**才执行，
而「应用」不关对话框。其实循环参数、热键等所有副作用都有同样问题。

修法：
- `SettingsWindow` 新增 `Applied` 事件，`ApplyAll()` 末尾触发
- `MainWindow` 把副作用抽成 `ApplySettingsSideEffects(dlg)`（清预读缓存、重建下拉、
  字体、热键、SetOutputDevice、循环模式下拉同步、时间线重算），
  「应用」事件与关窗后各调一次（全部幂等）

## 修复 2：框选会误触发拖动排序

根因：可排序列表里按在行上，拖过 4px 阈值立即进入排序，想框选无从下手。

修法（用户定的「延迟动作」）：按在行上先等 **300ms** —
- 按住满 300ms → 进入可拖排序状态（光标变十字箭头提示），再拖 = 排序
- 不到 300ms 就拖 → 框选（并废掉本次排序资格，防止框选中途延迟到了变排序）
- 锁定列表 / 空白处 / Ctrl 起拖行为不变
