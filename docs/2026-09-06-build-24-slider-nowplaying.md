## 3. 新增「作品全名」小字行

插在曲名行和 `44100Hz` 行之间：

```
東方紅魔郷 - 09 - 曲名                          16px
東方紅魔郷　〜 the Embodiment of Scarlet Devil.   11px，TextFaint
44100Hz / 2ch / 16bit · intro … · loop … · 总长 …
```

色值 `TextFaint`（`#71717A`）= 「霊界版」按钮**灰显（该曲没有灵界版）**时的文字色。

用户原话是「未激活灵界版那个按钮里字的深浅」，有两种理解：
- 按钮灰显 → `TextFaint`（我选的）
- 按钮可用但没切过去 → 正常 `Text` 亮度

**选错了用户会说是，结果确认是对的。**

全名取 `GameDef.Name`（来自各游戏 `おまけ.txt` 首行，含副标题）。
两处赋值：`PlayTrack`（换曲）和 `TrackGrid_SelectionChanged`（选中别的行）。
