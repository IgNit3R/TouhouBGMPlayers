### 报错：CS0104 撞名（8 处）

`Application` 在 `System.Windows.Forms` / `System.Windows` 之间歧义，
`Brush` 在 `System.Drawing` / `System.Windows.Media` 之间歧义。

**根因**：`UseWindowsForms=true` 时 SDK 自动注入全局 using。注入点：

```
sdk/10.0.400/Sdks/Microsoft.NET.Sdk.WindowsDesktop/targets/
  Microsoft.NET.Sdk.WindowsDesktop.WindowsForms.props:23-24
```

条件为 `UseWindowsForms == true and ImplicitUsings == true/enable`，
且该文件由 `Microsoft.NET.Sdk.WindowsDesktop.props:174` 在**项目体之前**导入。

**修复（两层，互为兜底）**：

1. `ThbgmPlayer.csproj` 加 `<Using Remove="System.Windows.Forms" />` 与
   `<Using Remove="System.Drawing" />` —— 因为是 .props 先行导入，项目体里的 Remove 生效。
2. 需要的文件加 using 别名（别名优先级高于全局 using）：
   - `App.xaml.cs`：`using Application = System.Windows.Application;`
   - `UI/SettingsWindow.xaml.cs`：`using Brush = System.Windows.Media.Brush;`
     `using Color = System.Windows.Media.Color;`

规则固化：**凡要用 WinForms 的地方一律写全称**（目前仅 `FolderBrowserDialog` 一处）。
