# 待办：切版本按钮的文案要按作品区分

日期：2026-09-10 记录（用户提出："新典里显示一个灵界版就很怪异"）

## 现状

「主版 / 副版」机制是**通用的**，但界面文案**硬编码成 TH13 专用的「霊界版」**：

| 位置 | 现状 |
|---|---|
| `src/MainWindow.xaml:221-223` | `<Button x:Name="AltButton" Content="霊界版" … ToolTip="切换到灵界版（仅 TH13 部分曲目可用）"/>` |
| `src/MainWindow.xaml.cs:1150` | `AltButton.Content = _engine.UsingAlt ? "霊界版 ✓" : "霊界版";` |
| `src/MainWindow.xaml.cs:1158` | 空状态时 `AltButton.Content = "霊界版";` |
| `src/MainWindow.xaml.cs:1134` | `NowPlayingDetail` 前缀：`"霊界版 · " + _nowDetail` |
| `Themes/DarkTheme.xaml` | 激活样式 `AltActiveButton`（紫色）——样式本身可复用，不必按作品区分 |

机制侧没有问题：`TrackDef.Alt` 承载副版，`HasAlt` 决定按钮可用性，预读缓存也按「主/副」成对预读。
新典（TH06NC）复用的正是这套：**主版 = 新编曲（`data/bgm/`）、副版 = 原编曲（`data/bgm2/`）**。

## 问题

新典里按钮显示「霊界版」，与它实际含义（新旧编曲切换）**完全不符**，语义误导。

「灵界版」是 TH13（東方神霊廟）特有的设定用词，不该作为通用副版的默认文案。

## 提案（待用户确认后实施）

1. **索引加作品级字段**（如 `"altlabel"`）：TH13 = `霊界版`；TH06NC = 待定（见下）；其余作品无此字段。
2. **文案取该字段**，缺失时回退到通用词（如「副版」）：
   - `AltButton.Content`（含 ` ✓` 激活态）
   - `AltButton.ToolTip`（现在写死「仅 TH13 部分曲目可用」，应改为按作品动态描述或删掉括注）
   - `NowPlayingDetail` 前缀
3. 无副版的曲目（如新典第 16 首新曲）按钮禁用 —— `hasAlt` 逻辑**已覆盖**，无需改动。
4. 激活样式（紫色）建议保持不变，不按作品分色（避免样式膨胀）。

**影响面**：仅 1 个索引字段 + 3 处文案引用；不触碰播放内核/预读/交叉淡化逻辑。

## 待定（需用户定）

- 新典副版的中文词用什么？候选：**原典版** / 原曲版 / 原编曲
  （此前讨论里 `bgm2/` 被称作「原编曲」，玩家习惯可能更认「原曲」）
- 是否顺便给 TH13 之外的作品都定义文案（目前只有 TH13 与新典用到副版机制）

## 已实施（2026-09-10，用户改为「在播放列表行新做一个按钮」）

用户重新设计：**不再改播放控件行那个按钮的文案**，而是在**播放列表行**新做一个数据驱动的副版切换按钮。

**做法（通用化接口 + 按作品显隐）**：

| 项 | 实现 |
|---|---|
| 数据 | `GameDef` 加 `lm` / `la`（主版/副版按钮文字）+ `HasVariantLabels`；索引里 th06nc = `新典` / `原典`；**TH13 暂不加标签**（继续用旧的霊界版按钮，零变化） |
| 位置 | `MainWindow.xaml` 播放列表行改为 5 列，`VariantButton` 在 ComboBox 正右边（col2），摘要顺延 col4 |
| 文案 | 显示**当前状态**：主版=「新典」、副版=「原典」 |
| 配色 | 主版（新典）= 绯红 `#C2344A`（边框 `#D9536A`）；副版（原典）= 稍暗的红 `#9E2B3C`（边框 `#B33A4E`）；各含 hover/pressed |
| 显隐 | **按「当前所选播放列表所属作品」判断**（收藏/自定义列表 `GameId==null` 时回退到正在播放曲目的作品）；该作品有标签 → 显示，否则隐藏 |
| 可切换性 | 正在播该作品的曲目且该曲有副版 → 可点；未播该作品、或该曲无副版（新典 #16）→ **禁用** |
| 样式规则 | **禁用 ⇒ 默认（隐式）按钮样式**（`ClearValue`，与旧「霊界版」按钮在无副版曲目上的一致）；**可用 ⇒ 才上版本配色**（主版绯红 / 副版暗红）|
| 去重 | 有标签的作品上，隐藏播放控件行原有的「霊界版」按钮（否则新典会出现两个切换入口） |
| 点击 | 直接复用原 `Alt_Click` 路径 → 预读配对/交叉淡化/底部前缀等既有行为不变 |
| 样式 | 新增 `VariantMainButton` / `VariantAltButton`，结构照 `AltActiveButton`；**旧 `Alt*` 画刷与样式一行未改**（git diff 为纯新增） |

**验证**：构建 0 警告 0 错误；探针断言「全表仅 th06nc 带标签」「th13 HasVariantLabels=false 且仍有 13 首副版」「th06nc 17/18 有副版、#16 无」全通过；`check_src.py` 全通过。

### 后续修订（2026-09-10 晚，用户确认规则）

**两个按钮（旧「霊界版」+ 新「新典/原典」）的显隐统一跟「当前播放列表」走，可点性跟「正在播放的曲目」走。**

- 新增 `ContextGames()`：由当前列表项推出涉及的作品集——作品列表→该作品；收藏→收藏内作品去重；自定义→条目内作品去重；
  取不到时回退到正在播放曲目的作品。
- 新增 `RefreshVariantControls()` 作为**唯一刷新入口**（先算 context 再刷两个按钮），调用点：构造期 / `LoadPlaylist` 末尾 /
  `PlayTrack` / `Alt_Click`。**此前切列表只刷了新按钮**，导致"播过新典后切回 TH13，旧按钮不再出现"的回归。
- 旧「霊界版」按钮：列表内含「有副版且无标签」的作品（TH13）才显示；其余作品列表**由灰显占位改为隐藏**（用户已同意）。
- 新典按钮：列表内含带标签作品才显示；未播该作品或该曲无副版 → 可见但禁用 + 默认样式。
- 收藏/自定义混合列表下**可能同时显示两个按钮**，各自只在播到自己作品的曲目时可点。
